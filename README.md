# cl1

Next.js landing page for CroweOS Systems, a planned lab management product for mycology, with placeholder copy, screenshots, and testimonials.

## Status

early stage

One commit, 2025-07-13, generated with v0.dev (`generator: 'v0.dev'` in `app/layout.tsx`). The page builds and serves. Nothing behind it exists in this repository: the contact form stores nothing, the screenshots are `placeholder.svg`, and the hero logo path returns 404.

## What runs today

- `app/page.tsx`: one static route that stacks nine sections from `components/sections/` (header, hero, problem-solution, features, screenshot carousel, testimonials, pricing, CTA banner, footer).
- `app/api/contact/route.ts`: accepts a JSON POST, logs the body with `console.log`, returns 200. It does not validate, email, or save anything.
- `components/ui/`: 50 shadcn/ui files. Most are unused by the page.
- `components/theme-toggle.tsx`: light and dark mode via `next-themes`.

## Roadmap

None. No work has been done since the initial commit. If the page is revived, the first tasks are real copy, real screenshots, a working contact handler, and fixing the hero image path.

## Limits

- Not a product. This is a marketing page for software that is not in this repository.
- `components/sections/testimonials.tsx` holds three generated quotes with `placeholder.svg` avatars. They did not come from customers. Do not publish them.
- `components/sections/pricing.tsx` shows three tiers with dollar figures generated by v0. They are not Crowe Logic prices.
- `components/sections/features.tsx` names four features with marketing claims ("cut contamination incidents by 40%" appears in the testimonials). No code, data, or study in this repository supports any of them.
- `components/sections/hero.tsx` loads `/logo-full-transparent.png`. The file is not in `public/` (404 on the run above). `public/logo-full.png` exists.
- `components/sections/screenshot-carousel.tsx` shows four `placeholder.svg` frames, not product screenshots.
- `next.config.mjs` sets `typescript.ignoreBuildErrors: true` and `eslint.ignoreDuringBuilds: true`. Type errors are not caught by the build.
- `package.json` pins `next` at 15.2.4 and uses `latest` for three dependencies. Dependabot PR #1 proposes `next` 15.4.7 and is left open.
- No tests.
